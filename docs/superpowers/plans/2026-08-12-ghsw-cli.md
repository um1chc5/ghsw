# ghsw CLI Implementation Plan

> **For agentic workers:** Execute task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Node.js CLI `ghsw` that manages GitHub HTTPS profiles via `gh` + git config, with installers and README.

**Architecture:** Commander CLI → profiles store (`~/.ghsw/config.json`) + `gh` wrappers + gitconfig read/write with backups and includeIf upsert.

**Tech Stack:** Node.js (ESM), commander, chalk, inquirer; shell out to `gh` and `git`.

## Global Constraints

- Hostname: `github.com` only in v1
- Auth: HTTPS + `gh` tokens, not SSH
- Config path: `~/.ghsw/config.json`
- Generated per-profile gitconfig: `~/.gitconfig-<profile-name>`
- Backup `~/.gitconfig` to timestamped `.bak` before edits
- Confirm before remove / `gh auth logout`
- No duplicate `includeIf` for the same folder

## File Structure

| File | Responsibility |
|------|----------------|
| `package.json` | bin `ghsw`, deps |
| `cli.js` | Commander commands |
| `lib/profiles.js` | Load/save/CRUD profiles |
| `lib/gh.js` | `gh` spawn helpers + parse status |
| `lib/git.js` | global user, includeIf upsert, backups, profile gitconfig files |
| `lib/prompts.js` | inquirer helpers |
| `install.sh` / `install.ps1` | Node/gh checks + PATH install |
| `README.md` | HTTPS guide + second-account walkthrough |
| `tests/*.test.js` | profile + gitconfig unit tests |
